# CampusFlow Design Decisions

## Data Structure

We will store tickets in a list of
Python dictionaries.

## Ticket IDs

Each ticket will have a unique ID
such as T001, T002, and T003.

## Input Validation

Invalid inputs will raise ValueError.

## Storage

Tickets will be saved in data/tickets.json.

## Testing

We will use Python unittest.

## Responsibilities

Engineer A:
Ticket creation, validation,
priority calculation and tests.

Engineer B:
Assignment, workflow,
queue, reports and tests.
